# JAVA graduate work

Дипломная работа по курсу "JAVA-разработчик"

## Стек технологий

- **Java 21**, Spring Boot 4.1.0
- **PostgreSQL, v16** — основная база
- **Liquibase** — миграции схемы PostgreSQL
- **Spring Data JPA** — работа с PostgreSQL
- **Swagger/OpenAPI** (springdoc) — документация API
- **MapStruct** — маппинг DTO/сущностей
- **Lombok** — генерация бойлерплейта
- **Alfresco Community** - файловое хранилище аватарок и рисунков объявлений

## Архитектура

Приложение выполнено по REST API технологии.
```
controller → service → repository (JPA → PostgreSQL)
              ↓
              filestorage (Alfresco)
```

- **Пользователи** — регистрация, авторизация, получение информации об авторизованном пользователе, изменение пароля, 
                     добавление\обновление автара пользователя, редактирование информации о пользователе
- **Рекламные объявления** - добавление объявления, получение всех объявлений, получение подробной информации об объявлении,
                             удаление объявления, обновление объявления, получение объявлений авторизованного пользователя,
                             обновление рисунка объявлений
- **Комментарии к объявлению** — добавление, изменение, удаление, получение всех комментариев к заданному объявлению

## API

### Пользователи
| Метод | Путь                  | Описание                                             |
|-------|-----------------------|------------------------------------------------------|
| POST  | `/login`              | Авторизация пользователя                             |
| POST  | `/register`           | Регистрация пользователя                             |
| POST  | `/users/set_password` | Изменение своего пароля авторизованным пользователем |
| GET   | `/users/me`           | Получение информации об авторизованном пользователе  |
| PATCH | `/users/me`           | Обновление информации об авторизованном пользователе |
| PATCH | `/users/me/image`     | Обновление аватара авторизованного пользователя      |

### Рекламные объявления
| Метод  | Путь              | Описание                                          |
|--------|-------------------|---------------------------------------------------|
| GET    | `/ads`            | Получение всех объявлений                         |
| POST   | `/ads`            | Добавление объявления                             |
| GET    | `/ads/{id}`       | Получение информации об объявлении                |
| DELETE | `/ads/{id}`       | Удаление объявления                               |
| PATCH  | `/ads/{id}`       | Обновление информации об объявлении               |
| GET    | `/ads/me`         | Получение объявлений авторизованного пользователя |
| PATCH  | `/ads/{id}/image` | Обновление картинки объявления                    |

### Комментарии объявлений
| Метод | Путь                              | Описание                            |
|-------|-----------------------------------|-------------------------------------|
| GET   | `/ads/{id}/comments`              | Получение комментариев объявления   |
| POST  | `/ads/{id}/comments`              | Добавление комментария к объявлению |
| GET   | `/ads/{id}`                       | Получение информации об объявлении  |
| DELETE| `/ads/{adId}/comments/{commentId}`| Удаление комментария                |
| PATCH | `/ads/{adId}/comments/{commentId}`| Обновление комментария              |

Swagger UI: `http://localhost:8080/swagger-ui.html`

## Запуск

### Требования

- JDK 21
- Docker (PostgreSQL) для фронтеда

### Запуск инфраструктуры

```bash
docker run -d --name postgres -e POSTGRES_DB=java_graduate_work -e POSTGRES_USER=java_user -e POSTGRES_PASSWORD=java -p 5432:5432 postgres:16
```

### Сборка и запуск
```bash
./mvnw spring-boot:run
```

## База данных

- **PostgreSQL** — таблицы `user`,`advertising`,`advertising_comments`, управляется Liquibase
